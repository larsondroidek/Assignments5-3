Paragraph Styles

Default Paragraph

Good typography makes text easy and pleasant to read. The font, size, spacing and alignment all work together to guide the reader's eyes across the page.

Tight vs. Comfortable Line Height

This paragraph uses a tight line-height of 1.1. Lines sit close together, which can feel crowded when the text runs over several lines like this one does.

This paragraph uses a comfortable line-height of 1.8. The extra space between lines makes longer text easier to read, which is why body text usually uses 1.5 to 1.8.

Text Alignment

Left-aligned text is the default and the easiest to read for long paragraphs.

Center-aligned text works well for short quotes and titles.

Right-aligned text can be used for dates, signatures and captions.

Justified text stretches each line to the same width, creating clean edges on both sides. It looks formal, like a newspaper column or a book page.

Letter-Spacing

Wide letter-spacing for small uppercase labels

Tight letter-spacing for large display text
